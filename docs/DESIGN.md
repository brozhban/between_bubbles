# Wine Diary — Style Reference
> Warm editorial diary: quiet earth-tone surfaces, serif entries, muted wine-chapter accents

**Theme:** light + dark (see tokens below)
**Platform:** mobile web, single-column, bottom nav

## Tokens — Typography

### Serif — Display / Entry titles
- **Family:** Lora, EB Garamond, Freight Text Pro (сериф-замена BasicCommercial/Caslon)
- **Weights:** 300, 400
- **Sizes:** 16px (карточка в ленте) / 24px (заголовок формы) / 28px (имя вина, крупно)
- **Line height:** 1.2
- **Role:** название вина, заголовки экранов, текст заметок в форме

### Sans small-caps — Labels / Nav / Buttons
- **Family:** Inter, Suisse Int'l, Work Sans
- **Weights:** 400, 500
- **Sizes:** 11px (капс-лейблы) / 13px (нав, кнопки) / 14px (значения полей)
- **Letter spacing:** 0.06–0.09em, всегда UPPERCASE для лейблов и навигации
- **Role:** лейблы полей формы, нижняя навигация, метаданные карточки (тип · цена · сахар)

## Tokens — Spacing & Shapes

- **Base unit:** 4px
- **Density:** compact-comfortable (мобайл, но с воздухом между блоками формы: 24px)
- **Radius:** 0px везде — карточки, инпуты, кнопки, теги квадратные (наследуем print-характер Essie)
- **Border:** 1px, только нижняя граница у полей ввода (underline-inputs), без боксов
- **Card padding:** 16px
- **Section gap (форма):** 32px между блоками (Основное / Профиль вкуса / Аромат / Оценка)
- **Elevation:** отсутствует — никаких теней, глубина только через смену цвета поверхности

## Components

### Bottom Navigation (мобайл)
Лента · Добавить · Профиль/Друзья. Иконки-контуры + подпись капсом 11px. Активный пункт — подчёркивание 2px в `--color-accent-b`. Фон = `--color-surface`, без тени, разделитель 1px сверху в `--color-border`.

### Feed Entry Card (мультипользовательский)
Full-bleed фото этикетки без рамки/радиуса (высота ~160px) → под фото: аватар + имя автора (12px) в правом верхнем углу поверх фото на полупрозрачной плашке; название вина серифом 16px; строка метаданных капсом 11px `ТИП · ЦЕНА · САХАР`; справа — Rating Pill (см. ниже). Заметки не показываются в ленте, только по тапу на карточку.

### Rating Pill
Компактный овал/квадрат (0 radius) с числом от 0.5 до 5.0 с шагом 0.5 (10 значений), например `4.5`. Цвет фона зависит от диапазона: 0.5–2.0 → `--color-border` (нейтральный), 2.5–3.5 → `--color-accent-a` (Dusty Rose), 4.0–5.0 → `--color-accent-b` (Mustard Olive). Текст — Stone Charcoal/Warm Bone, sans 13px medium.

### Rating Input (форма) — Half-Star Segmented Control
10 сегментов-тиков в ряд (шаг 0.5) вместо звёзд — тонкая горизонтальная линия (аналог underline-input Essie), где заполненная часть закрашена `--color-accent-b`, над ней крупное число выбранного значения серифом 28px по центру. Тап/свайп по линии — как в аудио-скраббере.

### Scale Slider — Тело / Кислотность / Танины
Три одинаковых горизонтальных слайдера: тонкая линия 1px `--color-border`, точка-ползунок квадратная 0 radius в `--color-text`. Подпись капсом сверху слева (`ТЕЛО`), подписи-полюса капсом 10px по краям (`Лёгкое` — `Полнотелое`, `Свежее` — `Мягкое`, `Мягкие` — `Терпкие`). Без чисел — только позиция.

### Flavor Tag Chips — Категории вкуса / Аромат
Прямоугольные чипы (0 radius), border 1px `--color-border`, невыбранные — прозрачный фон; выбранные — заливка `--color-accent-a` или `--color-accent-b` (чередовать по группам: фруктовые/цветочные — Dusty Rose, землистые/пряные — Mustard Olive). Текст капс 11px. Множественный выбор, перенос строк.

### Underline Input — Название / Цена / Тип / Выпито
Bottom-border-only, 1px `--color-border`, без фона и радиуса. Лейбл капсом 11px над полем в `--color-text-muted`. Фокус — граница становится `--color-text` (2px).

### Notes Field — Заметки / Ощущение
Многострочный textarea без рамки-бокса, только нижняя линия 1px, текст серифом 15px line-height 1.4 — визуально страница дневника, а не UI-форма.

### Outlined Action Button
Primary action (Сохранить запись): full-width, border 1px `--color-text`, прозрачная заливка, текст капс 13px, вертикальный паддинг 14px. Никаких залитых кнопок — это единственный тип CTA в системе.

### Text Link with Arrow — Secondary action
Для второстепенных действий (Отмена, Посмотреть все, Добавить фото): текст капс 13px + стрелка (→ / ↓), подчёркивание только на hover/active.

## Do's and Don'ts

**Do**
- Держать 0px radius везде — квадратные карточки, инпуты, чипы, кнопки.
- Использовать сериф только для имени вина и заметок — это «рукописный» голос дневника.
- Использовать Dusty Rose и Mustard Olive точечно (теги, рейтинг), не как фон целых экранов.
- Разбивать форму добавления на 4 блока-шага, не показывать все 13 полей одним длинным списком.
- Показывать автора записи на карточке — это социальный дневник, а не личный список.

**Don't**
- Не добавлять тени, градиенты, скругления — это ломает print/editorial характер.
- Не использовать звёзды для рейтинга — только числовой сегментированный контрол с шагом 0.5.
- Не заливать основную кнопку сплошным цветом — только outline или text-link.
- Не смешивать более двух акцентных цветов на одном экране одновременно.

## Screens

1. **Лента** — вертикальный скролл Feed Entry Card, фильтр сверху (Все / Друзья / Мои).
2. **Добавление записи** — 4 шага (свайп/аккордеон): Основное → Профиль вкуса → Аромат и категории → Оценка и заметки.
3. **Карточка вина (детально)** — фото крупно, вся информация из формы, кто и когда добавил, комментарии друзей (опционально).
4. **Профиль** — аватар, список своих записей (те же карточки), подписки.
